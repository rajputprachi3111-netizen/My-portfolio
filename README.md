# 🚀 The Angry East Indian's Work
### Sci-Fi Developer & 3D Artist Portfolio // Orbital Command HUD

A production-ready **Responsive Web Design (RWD/RWB)** Sci-Fi developer and 3D artist portfolio website built with **React**, **Three.js (@react-three/fiber, @react-three/drei)**, **TypeScript**, and **Tailwind CSS**.

---

## 🌟 Visual Theme & Aesthetics
- **Theme:** Deep-space Sci-Fi Command Center / Orbital Telemetry HUD.
- **Palette:**
  - Void Black (`#05070D`) with real-time 3D twinkling animated starfield.
  - Electric Cyan (`#00F0FF`) & Deep Cobalt (`#1E40AF`) for orbital rings and holographic HUD lines.
  - Holographic White (`#F8FAFC`) with amber (`#F59E0B`), violet (`#8B5CF6`), and emerald (`#10B981`) sector accents.
- **Typography:** Google Fonts `Orbitron` (sci-fi headers), `Inter` (body copy), and `JetBrains Mono` (telemetry readouts).
- **Glassmorphism:** Translucent `backdrop-blur-md` panels with glowing 1px borders, corner bracket framing `[ ]`, and scanline overlay.

---

## 🪐 Core Interactive 3D Solar System (Navigation Engine)
- **Central Glowing Sun:** Represents the core identity hub: **"The angry east indian's work"** (Full-Stack Sci-Fi Developer & 3D Artist).
- **4 Orbiting Interactive Planets:**
  1. **Sector Cyber-I (Electric Cyan):** Web Engineering & Mission Logs.
  2. **Sector Vulcan-II (Amber / Gold):** The Blender Foundry (3D Modeling & Shaders).
  3. **Sector Pulsar-III (Violet):** Subspace Broadcasts (YouTube Media Hub).
  4. **Sector Beacon-IV (Emerald / Cyan):** Hailing Frequencies (Comms Array & Social Relay).
- **Interactions:**
  - Hovering over a planet highlights its glowing orbital ring and shows a floating HUD telemetry tooltip.
  - Clicking/tapping smoothly animates the camera toward that sector and slides open its responsive holographic drawer.
  - Touch-optimized `OrbitControls` for mobile & tablet (one-finger rotate, two-finger pinch/zoom).
  - Quick-access bottom **Planetary Pill Bar** for one-thumb mobile navigation.
  - One-click **"2D / Low-Power Mode"** toggle button for battery saving and accessibility.
